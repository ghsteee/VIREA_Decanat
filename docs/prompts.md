# Шаблоны задач для агентов

Готовые тексты, чтобы ставить задачи одинаково. Подставь значения в `<…>`. Хорошая задача: одна цель, номер требования, критерий готовности, что не трогать.

## Задача на код (Codex или Claude Code)

```
Сделай <номер требования, например R3> из docs/PRD.md.
Контекст: <одна-две фразы, зачем это и где в интерфейсе>.
Готово, когда: <критерий из PRD или свой, проверяемый>.
Не трогай: <файлы или зоны другого человека, если важно>.
Перед началом прочитай AGENTS.md и docs/status.md. Работай в ветке feat/<id>-<кратко>, открой PR по шаблону, отметь задачу в docs/status.md и добавь запись в журнал ИИ.
```

## Исправление ошибки

```
Ошибка: <что видим, где, как воспроизвести>.
Ожидалось: <как должно быть, ссылка на требование>.
Найди причину, исправь и добавь тест, который ловит эту ошибку. Ветка fix/<id>-<кратко>.
Если ошибку сделал ИИ — в записи журнала заполни раздел «Ошибки ИИ»: ошибка → как заметили → как исправили → правило на будущее.
```

## Ревью PR

```
Проверь PR #<номер> по чек-листу из AGENTS.md и по требованиям <ID> из docs/PRD.md.
Отдельно: чужие данные недоступны (запрос с чужим id → 404), нет ключей и реальных персональных данных, экран работает на 360 px.
Ответь списком: файл:строка — проблема — как исправить. Ничего не меняй сам.
```

Claude Code для этого запускает субагентов из `.claude/agents/`: `security-reviewer`, `ui-reviewer`, `test-writer`.

## Картинка (ChatGPT)

```
Нарисуй <что: логотип / иллюстрацию пустого состояния «…» / аватар-заглушку>.
Стиль: <из docs/design-system.md: цвета, настроение>. Формат: <SVG или PNG, размер, прозрачный фон>.
Ограничения: ВТУ ВИРЭА — вымышленный вуз; без сходства с гербом и логотипом РТУ МИРЭА, без реальных людей, без текста кроме «ВТУ ВИРЭА».
Сделай 3 варианта. После выбора дай текст записи журнала ИИ по шаблону docs/ai-log/_template.md.
```

## Если агент начинает с нуля

Это же — проверочная задача при подключении нового Codex.

```
Ты подключаешься к проекту без истории. Всё, что тебе нужно, есть в этом репозитории.
1. Прочитай по порядку: AGENTS.md, docs/context.md, docs/status.md, docs/PRD.md, docs/hackathon-task.md.
2. Ответь в чате: что за проект и его главная идея (2–3 предложения); 5 правил, которые нельзя нарушать; какая задача из docs/status.md подходит тебе первой и почему; чего не хватило — противоречия, непонятные места, ссылки в никуда, каждый пункт с файлом и строкой.
3. Ничего не меняй в документах и коде. Единственное — запись журнала docs/ai-log/entries/<дата>_<время МСК>_<твой код: codex-alena / codex-partner>_onboarding-check.md по шаблону docs/ai-log/_template.md с итогом проверки.
4. Открой PR с этой записью: docs: проверка онбординга <Codex Алёны / Codex напарника>.
```
