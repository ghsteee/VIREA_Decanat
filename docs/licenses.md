# Сторонние материалы и лицензии

Условие хакатона: библиотеки, шрифты, иконки и изображения — только с лицензией, которая это разрешает. Добавил что-то стороннее (кроме npm-зависимостей с открытой лицензией) — допиши строку в том же PR.

| Что | Где используется | Источник | Лицензия |
| --- | --- | --- | --- |
| Lucide | Иконки | lucide.dev | ISC |
| shadcn/ui | Компоненты интерфейса | ui.shadcn.com | MIT |
| Days One | Только надпись логотипа «Деканыч» (переведена в кривые) | fonts.google.com/specimen/Days+One | SIL OFL 1.1 |
| Sofia Sans Extra Condensed | Заголовки, плитки и статусы в стиле табло, раздаём со своего сервера (`@fontsource-variable/sofia-sans-extra-condensed`) | fonts.google.com/specimen/Sofia+Sans+Extra+Condensed | SIL OFL 1.1 |
| Onest | Шрифт текста интерфейса, раздаём со своего сервера (`@fontsource-variable/onest`) | fonts.google.com/specimen/Onest | SIL OFL 1.1 |
| Цвета палитры | `docs/design-system.md` | Книга Санзо Вады «A Dictionary of Color Combinations», значения — набор данных github.com/mattdesl/dictionary-of-colour-combinations | Набор данных — MIT; сами цвета не охраняются |
| Логотип «Деканыч» | `docs/brand/dekanych-*` | Нарисован Claude Code для проекта | Создан для проекта |
| Картинки | `docs/brand/`, `public/brand/` | Сгенерированы ChatGPT командой | Созданы для проекта |

Шрифты интерфейса — Sofia Sans Extra Condensed и Onest (SIL OFL), раздаём со своего сервера, не с Google Fonts CDN. Days One — только в логотипе, в кривых.
