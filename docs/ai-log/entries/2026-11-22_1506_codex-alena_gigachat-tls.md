## Задача

Разобрать ошибку SELF_SIGNED_CERT_IN_CHAIN при проверке OAuth с VPS.

## Что сделал ИИ

В проверке и клиенте добавил корневые сертификаты из Node.js к пакету Минцифры. Изменение действует только на запросы GigaChat. Проверил синтаксис скрипта и типы. При повторной диагностике воспроизвёл исходную ошибку с официальными файлами. Их склейка без переноса строки повреждала границу PEM. Разбираю сертификаты отдельно и исправил команду сборки. С исходным склеенным файлом обновлённый клиент дошёл до HTTP 400 с намеренно неверным ключом. Повторный запрос с ключом проекта выполняется на VPS.

## Что проверил и поправил человек

Алёна установила пакет Минцифры и прислала код ошибки OAuth.

## Ошибки ИИ

Клиент передавал только пакет Минцифры в параметре ca. Этот параметр заменяет встроенное хранилище Node.js.

## Скриншоты

Диагностика выполняется в терминале.
