# Поиск по дисциплинам семестра в «Учёбе»

- **Дата и время:** 2026-11-22 04:40 МСК
- **Инструмент:** Codex (Алёна)
- **Кто ставил задачу:** Алёна
- **Этап плана:** 5 Should
- **Требования PRD:** G1, NF1

## Задача

По просьбе Алёны добавить поиск по дисциплинам в существующий раздел «Учёба».

## Что сделал ИИ

Добавил строку поиска над карточками. Список фильтруется по мере ввода по полному и короткому названию предмета текущего семестра. Поиск учитывает лишние пробелы, приравнивает «ё» к «е» и работает с буквами любого регистра. Порядок карточек сохраняется. При пустой выдаче появляется подсказка. Крестик очищает строку и возвращает фокус в поле.

На ширине 360 px в WebKit и 1366 px в Chromium проверены фильтрация, пустая выдача и сброс. Сборка, проверка типов, линтер, 10 модульных и 20 браузерных тестов прошли.

## Что проверил и поправил человек

Проверка Алёной впереди.

## Ошибки ИИ

Первая локальная сборка не смогла упаковать зависимости, подключённые символьной ссылкой. Для повторной проверки используется копия зависимостей внутри рабочей папки.
