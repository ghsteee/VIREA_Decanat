## Задача
> начни делать задачи напарника

Задача 3.2 — Docker Compose и Caddy на российском VPS. VPS ещё не выбран, поэтому подготовлены файлы и инструкция.

## Что сделал ИИ
- `Dockerfile`: многоэтапная сборка на Debian (glibc для argon2 и Prisma), итоговый образ — standalone-сервер Next.js от непривилегированного пользователя.
- `docker-compose.yml`: PostgreSQL 16 с томом и проверкой готовности, приложение, разовые команды `tools` (миграции, сид), Caddy с HTTPS; `restart: unless-stopped`; порт базы наружу не открыт; сертификат Минцифры для GigaChat монтируется из `deploy/certs/` (в репозиторий не коммитится).
- `deploy/Caddyfile`: HTTPS, сжатие, заголовки безопасности, проксирование с честным `X-Forwarded-For` для лимита входа.
- [`docs/setup/deploy.md`](../../setup/deploy.md): первый запуск, обновление, утренний сброс демо по cron, проверка доступа к Docker Hub из РФ.
- Проверил standalone-сборку локально: сервер стартует, вход сотрудника по сидам работает.
