# Контекст проекта и принятые решения

Файл для агента, который пришёл без истории. Здесь — что уже решено и почему. Не пересматривай эти решения сам: если считаешь, что решение надо поменять, предложи это человеку, а после согласия допиши новую строку в таблицу.

## Команда и как мы работаем

- Два человека: **Алёна** (капитан, GitHub `ghsteee`) и **напарник**. Оба не обязаны уметь программировать: код пишут ИИ-агенты, люди ставят задачи и проверяют результат.
- Агенты: Claude Code (Алёна, проект claude.ai), Codex Алёны, Codex напарника, ChatGPT (картинки). Общие правила — `AGENTS.md`.
- Язык проекта — русский: документы, коммиты, PR, тексты интерфейса. Код (имена переменных, файлов) — на английском.
- Время — московское (UTC+3). Сегодняшнюю дату бери из системы, а не из памяти модели.
