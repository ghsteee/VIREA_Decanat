# ИИ-помощник: GigaChat или YandexGPT

Исследование для AI1–AI3 и открытого вопроса PRD «ИИ-провайдер для помощника». Дата: 11.11.2026, Claude Code.

## Коротко

**Рекомендация: GigaChat как основной провайдер, YandexGPT — запасной.** Для хакатона у GigaChat есть бесплатный режим для физлиц без привязки карты, с большим запасом токенов. У YandexGPT бесплатного режима нет, есть стартовый грант Yandex Cloud от 4 000 ₽, но для него нужна карта. В коде провайдер прячем за одним интерфейсом, чтобы переключение было заменой одного модуля и переменных в `.env`.

Сравнение «на 5 вопросах» ещё не сделано: для него нужны ключи обоих сервисов. Вопросы и порядок проверки — ниже.

## Что это значит для проекта

- **Лимит 20 запросов в час на студента (AI3)** держим на своём сервере, независимо от провайдера.
- **Один поток у GigaChat Freemium.** Если двое студентов спросят одновременно, второй запрос подождёт. Для демо жюри это не страшно, но на сервере нужна очередь с таймаутом и понятный ответ «Деканыч думает, подожди пару секунд».
- **Некоммерческое использование.** Прототип для хакатона не продаётся, поэтому Freemium подходит. Если проект пойдёт дальше — покупать пакет.
- **Объём.** Один ответ с контекстом документов — порядка 2–4 тыс. токенов. 40 млн токенов Pro хватит примерно на 10 тысяч ответов: на хакатон с запасом.
- **Поиск по документам (AI1).** Для начала хватит простого поиска по ключевым словам в своей базе пунктов. Векторы (embeddings) — только если поиск по словам не справится.

## Проверка на 5 вопросах (нужны ключи)

Ключи получает Алёна: GigaChat — в личном кабинете на developers.sber.ru (Freemium, без карты), YandexGPT — в Yandex Cloud (стартовый грант, нужна карта). Ключи хранятся только в `.env` на сервере или в секретах среды, в репозиторий не попадают.

Вопросы — по демо-документам ВТУ ВИРЭА (см. ниже), одинаковые для обеих моделей, с одним и тем же системным промптом:

1. Как получить справку об обучении и сколько она делается?
2. Сколько баллов нужно, чтобы допустили к экзамену?
3. Можно ли пересдать экзамен, если заболел, и что для этого нужно?
4. Какие документы нужны для материальной помощи?
5. Вопрос без ответа в документах: «Когда начнётся летняя практика?» — модель должна честно сказать, что не знает, и предложить написать в дирекцию.

Оцениваем: ответ верный по документу; есть ссылка на пункт; нет выдуманного; тон на «ты», коротко; время ответа.

## Открытые вопросы PRD: шкала оценок и документы

Открыть положение о балльно-рейтинговой системе на mirea.ru из облачной среды не удалось: сайт закрыт защитой DDoS-Guard для зарубежных адресов. По сторонним источникам надёжных порогов нет.

**Предложение (решает Алёна):** не опираться на реальные правила МИРЭА, а написать короткое «Положение ВТУ ВИРЭА (демо)» — шкала 100 баллов, допуск, автомат, пересдача, справки, матпомощь. Это согласуется с правилом «только вымышленные данные» и с вымышленным вузом, а помощнику даёт базу, где у каждого пункта есть номер для ссылки (AI1). В интерфейсе помечаем «демо».
