# Опрос студентов: итоги (промежуточные, 20 ответов на 8 ноября)

Анкета «Каким должен быть цифровой деканат МИРЭА?» в Яндекс Формах, открыта до 10 ноября 20:00. После закрытия перезапускаем `analyze_survey.py` и обновляем этот файл. Сырые ответы в репозиторий не кладём.

## Главные боли

| Что | Результат |
| --- | --- |
| Как узнаю об изменениях в расписании | 2,0 из 5; 75% поставили 1–2 |
| Как смотрю само расписание | 4,05 из 5 — с просмотром всё неплохо |
| Новости и дедлайны | 2,85 из 5; 50% хотя бы раз пропускали дедлайн |
| Откуда узнаю об изменениях | 85% — от старосты |
| Сторонние приложения с расписанием | 90% пользуются |
| Сколько сервисов для учёбы | у 70% — три и больше |

Каналы уведомлений по опросу: push — 95%, Telegram — 90%. Для прототипа команда выбрала web push и e-mail. См. [журнал решений](../context.md).

Доверие к ИИ: 20% доверяют, 40% — если можно проверить источник, 25% не доверяют. Отсюда правило: каждый ответ помощника со ссылкой на пункт документа, а заявки он только готовит черновиком.

## Ограничения

Выборка маленькая, перекос ко 2 курсу и IT-институтам; два почти одинаковых свободных ответа; вопрос 20 никто не заполнил.
