## Принятые изменения

- Название вуза убрано с входа, из названия приложения и метаданных по отдельной просьбе пользователя. На входе остаётся «Деканыч · Цифровой деканат» и метка прототипа.
- Во всех местах отображения предмета используется Subject.name: учёба, день, неделя, месяц и новые уведомления об изменении пары. Поле shortName в БД не удаляется; миграция не нужна.
- Названия дисциплин — обычный шрифт Onest с переносами; Sofia остаётся для бренда, заголовков разделов, времени и числовых акцентов.
- На главной пустые состояния занимают компактную строку; рисунки сохранены. Дедлайны, результаты и заявка визуально отделены карточками.
- Цвета табло, логотип, навигация и согласованные анимации сохранены.

## За пределами изменения

Интеграции, импорт по фото, расчёт среднего балла по сторонним правилам, родительский кабинет и новые каналы связи не добавлялись. Если такие функции потребуются, сначала нужен выбор команды. Для «Сессии» по-прежнему нужны даты экзаменов из команды.
