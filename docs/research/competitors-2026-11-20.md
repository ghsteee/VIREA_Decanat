# Публичные проекты конкурса и идеи для Деканыча

На 20 ноября 2026 года поиск GitHub по названию «Цифровой деканат будущего» нашёл девять репозиториев. Несколько README прямо называют конкурс МГИМО или MGIMO AI Challenge 2026. Это основание сравнивать их как проекты того же конкурса; официальный список допущенных работ не проверялся.

Функции ниже описаны авторами в публичных README и спецификациях. Их работа на опубликованных стендах не тестировалась. Пустые репозитории и проекты других хакатонов в сравнение не включены. Код, изображения и тестовые пароли конкурентов в проект не переносились.

## Что предлагается согласовать

1. **Личное домашнее задание к паре.** В карточке будущей пары студент пишет заметку и отмечает выполнение. Запись видна только ему, хранится на сервере. Перенос пары сохраняет заметку благодаря привязке к UUID. Первая версия без вложений и автоматической отправки преподавателю. Требуются таблица, серверная проверка владельца и тест на чужой ID. Текущий PRD относит задания к зоне СДО и исключает их из прототипа; выбор этой функции должен явно изменить это ограничение.
2. **Справочник «Мой деканат».** Из заявок и профиля открывается страница вымышленного учебного отдела с темами обращений, кабинетами и часами приёма. Состав и часы команда должна подтвердить как демо-данные. Первая версия без чата, личных телефонов и внешних интеграций.
3. **Уточнения по заявке и ожидаемый срок.** Вместо отказа сотрудник может запросить уточнение, студент отвечает внутри заявки, история сохраняется. Ожидаемый срок рассчитывается по согласованным правилам вымышленного вуза. Нужны новый переход статуса, сообщения, уведомления и тесты обеих ролей. По объёму это больше первых двух вариантов.

Для ближайшего выпуска предлагается выбрать одну функцию — личное ДЗ или справочник. Поиск Ctrl+K из «Меридиана» тоже полезен, но поиск по учебным данным требует проверки прав для каждой категории результатов. Портфолио, лист ожидания и демо-часы лучше оценить после обязательных проверок доставки.

**Статус согласования:** новые функции из этого списка не добавлены. Реализация начинается после выбора напарником и учёта владельца экранов Алёны в PR.

## Что уже есть у Деканыча

Кабинет старосты, слоты выдачи без пересечения с парами, чек-лист допуска, подтверждение почты, push, календарный файл пары и иллюстрации уже входят в актуальный `main`. Их не нужно добавлять повторно как заимствованные идеи. ИИ-помощник находится в отдельной работе Codex Алёны и ждёт проверки GigaChat; этот обзор её не подменяет.
