# Дизайн-система ВТУ ВИРЭА

Владелец — Алёна. Версия 1.3 от 11.11: логотип «Деканыч», палитра «Табло» на молочной основе, плашки из словаря Санзо Вады, шрифты Days One + Onest. Черновик Claude Code, выбор цветов и шрифтов — Алёна. Основа: [PRD](PRD.md) (NF1, NF3, NF8, R3, T1, T2, X1). Наглядное превью — в Claude Artifact у Алёны. Источник правды — этот файл.

## Принципы

1. **Сначала изменения.** Перенос, отмена и новый дедлайн видны с первого взгляда. Ярче всего на экране метки изменений, а не украшения.
2. **Одной рукой на 360 px.** Колонка в одну ширину, главные действия внизу, касание не меньше 44×44 px.
3. **Статус не только цветом.** Каждая метка — иконка Lucide и слово. Цвет только подкрепляет.
4. **Нейтральная основа, цвет — по делу.** Фон, карточки и текст — молочный и графит. Цвет есть только у кнопок (тёмно-синий) и у плашек, у каждой плашки свой смысл.

## Цвета

Основа нейтральная — «молочный и графит». Акценты взяты из книги Санзо Вады «A Dictionary of Color Combinations» (1933): главный цвет — Vandar Poel's Blue из сочетания № 151, плашки — пастельные цвета той же книги. С фирменными цветами РТУ МИРЭА не совпадает. Значения цветов — из открытого набора данных mattdesl/dictionary-of-colour-combinations (MIT). Контраст посчитан по формуле WCAG 2.1, все пары текста не ниже 4,5 : 1 (AA). Выбор Алёны 11.11 из 20 палитр.

## Типографика

Два шрифта, оба SIL OFL 1.1, с кириллицей, раздаём со своего сервера (наборы `cyrillic` и `latin`, `font-display: swap`). Выбор Алёны 11.11 из сравнения пяти пар и 23 отдельных шрифтов.

- **Заголовки — Days One** (`@fontsource/days-one`). Широкий, округлый, с техничным оттенком — характер кабинета. Одно начертание (400), цифр одинаковой ширины нет, поэтому только для заголовков экранов и блоков, крупного времени ближайшей пары и логотипа. Не для текста, кнопок, меток и полей ввода. Запасной стек: `"Days One", "Onest", system-ui, sans-serif`.
- **Всё остальное — Onest** (`@fontsource-variable/onest`, вариативный 100–900, берём 400–700). Ровный современный гротеск, уравновешивает широкий заголовок. Есть функция `tnum` — цифры одной ширины. Запасной стек: `"Onest", system-ui, -apple-system, "Segoe UI", Roboto, sans-serif`.

Время, номера аудиторий и баллы — `font-variant-numeric: tabular-nums`, чтобы колонки не прыгали. У `<html>` всегда `lang="ru"`: от языка зависят переносы, кавычки и локальные формы букв в шрифтах.

| Токен | Размер / межстрочный | Шрифт и начертание | Где |
| --- | --- | --- | --- |
| `text-display` | 28 / 36 | Days One 400 | Заголовок экрана на десктопе |
| `text-title` | 22 / 28 | Days One 400 | Заголовок экрана на мобильном («Сегодня») |
| `text-heading` | 18 / 24 | Days One 400 | Заголовок блока («Изменения», «Дедлайны») |
| `text-body` | 16 / 24 | Onest 400 | Основной текст, название пары |
| `text-body-strong` | 16 / 24 | Onest 600 | Время пары, новое значение в «было → стало» |
| `text-small` | 14 / 20 | Onest 400 | Подписи: преподаватель, корпус, время публикации |
| `text-label` | 13 / 16 | Onest 600, межбуквенный 0,01 em | Метки и чипы |
| `text-caption` | 12 / 16 | Onest 400 | Плашка концепта, подвал |

Базовый размер 16 px — на iPhone меньший размер в поле ввода включает масштабирование. Меньше 12 px не используем.

## Сетка и отступы

- Шаг 4 px. Токены отступов: `1` = 4, `2` = 8, `3` = 12, `4` = 16, `5` = 20, `6` = 24, `8` = 32, `10` = 40 px.
- **360–767 px:** одна колонка, поля 16 px, промежуток между карточками 12 px, между блоками 24 px. Нижнее меню 64 px + safe-area.
- **768–1023 px:** поля 24 px, контент до 720 px по центру, блоки «Дедлайны» и «Оценки» на «Сегодня» — в две колонки.
- **от 1024 px:** нижнее меню заменяется боковой панелью 240 px. Контент до 1120 px, «Сегодня» в две колонки: слева пара и изменения, справа дедлайны, оценки, заявки (порядок T1 сохраняется при чтении сверху вниз и с клавиатуры).
- Горизонтальной прокрутки страницы нет нигде (NF1). Широкая таблица в кабинете сотрудника прокручивается внутри своего контейнера.

## Форма, тени, движение

| Токен | Значение | Где |
| --- | --- | --- |
| `--radius-sm` | 8 px | Метки, чипы, поля ввода |
| `--radius-md` | 12 px | Кнопки, карточки в списке |
| `--radius-lg` | 16 px | Карточка ближайшей пары, нижний лист (sheet) |
| `--shadow-1` | `0 1px 2px rgb(23 18 58 / .06)` | Карточки в светлой теме. В тёмной тень не видна — карточки отделяет `surface` от `bg` |
| `--shadow-2` | `0 8px 24px rgb(23 18 58 / .12)` | Всплывающие окна, нижний лист, тост |
| `--duration-fast` / `--duration-base` | 120 / 200 ms, `cubic-bezier(.2,0,0,1)` | Нажатия / появление листа и тоста |

При `prefers-reduced-motion: reduce` анимации отключаем, скелетон не мерцает.

## Компоненты

Основа — shadcn/ui. Ниже то, что собираем сами или настраиваем.

### Карточка пары

- Слева колонка времени `14:20` над `15:50` (tabular-nums), справа название, тип (Лекция / Практика / Лаб.), аудитория и корпус, преподаватель (вымышленный).
- Ближайшая пара на «Сегодня» — крупная карточка `radius-lg` с подписью «Через 25 минут», время начала крупно (Days One, 28 px) и кнопка второго плана «Как добраться» (`primary-soft`).
- С изменением: метка R3 над названием, «было → стало» в строке, которая изменилась. Ссылка «Подробнее» ведёт в ленту.
- Состояния: обычная, идёт сейчас (полоса `primary` слева 4 px и подпись «Идёт»), прошла (`text-muted`), отменена.

### Метка (Badge)

Высота 24 px, поля 8 px, `radius-sm`, иконка 14 px + слово `text-label`. Фон — `--plate-*`, текст и иконка — `--plate-ink` (у `danger` — белые). Сама по себе метка не кликается. Если строка кликабельна, зона касания — вся строка.

### Карточка дедлайна

Название, дисциплина, срок «до 20.12, 23:59» и обратный отсчёт «через 2 дня». Чекбокс «Сделано» 44×44 справа (D3). Источник — «от старосты» или «Дирекция ИИИ» мелким текстом. При сроке ≤ 2 дней — метка `warning`.

### Карточка заявки

Тип («Справка об обучении»), номер, дата подачи, метка статуса. Под меткой шкала из четырёх шагов «Подана → В работе → Готова → Выдана». Пройденные шаги закрашены `primary`, текущий подписан. Если «Отклонена», показываем причину и кнопку «Подать снова».

### Кнопки

| Вариант | Вид | Когда |
| --- | --- | --- |
| Главная | `primary` фон, `on-primary` текст | Одно главное действие на экране: «Отправить заявку», «Войти» |
| Вторичная | `surface` фон, граница `border-strong`, текст `text` | «Отмена», «Изменить» |
| Второго плана | `primary-soft` фон, `primary-soft-fg` текст | Действия рядом с контентом: «Как добраться», «Подключиться» |
| Тихая | без фона, текст `primary` | «Подробнее», «Все дедлайны» |
| Опасная | `plate-danger` фон, белый текст | «Отклонить заявку» (сотрудник) |

Высота 44 px (на десктопе можно 40 px для плотных таблиц сотрудника), `radius-md`, текст `text-body-strong`. Состояния: hover — затемнение на 8 %, нажатие — на 12 %, неактивна — 40 % непрозрачности и `aria-disabled`, загрузка — индикатор вместо иконки, ширина не меняется.

### Нижнее меню (мобильный)

Пять пунктов: Сегодня (`House`), Расписание (`CalendarDays`), Учёба (`GraduationCap`), Заявки (`FileText`), Профиль (`CircleUser`). На 360 px каждый по 72 px, иконка 24 px и подпись 12 px. Активный пункт — `primary` и плашка `primary-soft` под иконкой. Счётчик непрочитанного на «Сегодня» — розовая точка `plate-change` с числом `plate-ink`. Меню фиксировано внизу и учитывает `env(safe-area-inset-bottom)`.

### Плашка концепта (X1)

На экране входа — над формой, в подвале — на всех страницах. Текст ровно «Концепт для хакатона. ВТУ ВИРЭА — вымышленный вуз, прообраз — РТУ МИРЭА. Не официальный сервис». Стиль `text-caption`, `text-muted`, фон `surface-muted`, иконка `Info`. Не закрывается.

### Скелетон (NF2)

Серые блоки `surface-muted` в форме будущих карточек, `radius` как у карточек. Мерцание — 1,2 с, отключается при reduced motion. Пустой экран при загрузке не показываем.

### Пустые состояния (T2)

Иллюстрация ChatGPT до 120 px (`empty-today.png`, `empty-requests.png`), одна строка `text-body` и, если есть, тихая кнопка. Тексты: «Сегодня пар нет», «Всё по расписанию», «Дедлайнов на неделе нет», «Заявок пока нет».

### Ошибки и тосты (NF4)

Ошибка в форме — под полем, `danger-text`, иконка `CircleAlert`, поле с границей `danger-text`. Ошибка экрана — карточка с объяснением и следующим шагом: «Не получилось загрузить расписание. Проверь интернет и попробуй ещё раз» + «Повторить». Тост — внизу над меню, 4 с, `shadow-2`, с действием «Отменить», где это возможно.

## Логотип в интерфейсе

Сервис называется «Деканыч». Знак — «Одна пара»: драконьи глаза `#F9C1CE` на тёмно-синей табличке `#064F6E`, одинаковый в обеих темах. Файлы и правила — [`docs/brand/README.md`](brand/README.md).

- **Шапка:** знак 28–32 px + надпись «Деканыч» (Days One, в кривых), графитом в светлой теме и `#F3F0EA` в тёмной.
- **Вкладка и PWA:** только знак; иконка приложения — плашка на весь квадрат, глаза в безопасной зоне.
- **Экран входа:** знак крупно (96 px) и надпись; под ними подпись «цифровой деканат ВТУ ВИРЭА» и плашка концепта (X1).

## Тон текстов (NF8)

На «ты», коротко, глагол в начале действия. Без канцелярита.

| Так | Не так |
| --- | --- |
| Справка готова. Забери в 214-й до пятницы | Заявка переведена в статус «Исполнена» |
| Пару перенесли на 16:20 | Произведено изменение расписания занятия |
| Включить уведомления | Активировать push-подписку |
| Не тот пароль. Попробуй ещё раз | Ошибка аутентификации |

## Токены для кода

На этапе 3 токены переносятся в `app/globals.css` как CSS-переменные. Имена совпадают с shadcn/ui, чтобы компоненты подхватили их без правок:

| shadcn/ui | Наш токен |
| --- | --- |
| `--background` | `--bg` |
| `--foreground` | `--text` |
| `--card`, `--popover` | `--surface` |
| `--muted` / `--muted-foreground` | `--surface-muted` / `--text-muted` |
| `--primary` / `--primary-foreground` | `--primary` / `--on-primary` |
| `--secondary` | `--primary-soft` |
| `--accent` / `--accent-foreground` | `--primary-soft` / `--primary-soft-fg` |
| `--destructive` | `--plate-danger` |
| `--border` / `--input` | `--border` / `--border-strong` |
| `--ring` | `--focus` |
| `--radius` | `--radius-md` (12 px) |

Плашки (`plate-change`, `plate-danger`, `plate-warning`, `plate-success`, `plate-info`, `plate-head`, `plate-ink`) и `danger-text` добавляются в `tailwind.config` как цвета. Тёмная тема включается классом `dark` на `<html>` (выбор в профиле, P3), по умолчанию — системная.
