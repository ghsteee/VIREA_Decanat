# Бренд ВТУ ВИРЭА: логотип и картинки

Все картинки генерирует ChatGPT. Здесь — исходники и промпты, в `public/brand/` — файлы, которые использует сайт (папка появится вместе с каркасом приложения на этапе 3; до этого кладём всё сюда).

## Правила

- ВТУ ВИРЭА — вымышленный вуз. Никакого сходства с гербом, логотипом и фирменными цветами РТУ МИРЭА.
- Без реальных людей, без узнаваемых зданий кампуса.
- Логотип: читается на 32 px (иконка вкладки) и на 192/512 px (иконка PWA); есть вариант для тёмной темы.
- Цвета берём из `docs/design-system.md`, когда он появится.
