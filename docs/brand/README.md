# Бренд «Деканыч»: логотип и картинки

Сервис называется **«Деканыч»** (деканат + Змей Горыныч) — цифровой деканат вымышленного вуза ВТУ ВИРЭА. Логотип нарисовал Claude Code в SVG; иллюстрации пустых состояний и аватары делает ChatGPT. Здесь — исходники, в `public/brand/` — файлы для сайта (папка появится вместе с каркасом на этапе 3; до этого кладём всё сюда).

## Знак «Одна пара»

Пара драконьих глаз — раскосых, со зрачками-щелями — на тёмно-синей табличке. Горыныч всегда начеку и первым замечает, что изменилось. Табличка `#064F6E` (Vandar Poel's Blue), глаза `#F9C1CE` (Hermosa Pink), зрачки цвета таблички. Одинаков в светлой и тёмной теме: контраст глаз и таблички 5,8 : 1. Надпись «Деканыч» — Days One, переведена в кривые, поэтому логотип не зависит от шрифта.

## Правила

- ВТУ ВИРЭА — вымышленный вуз. Никакого сходства с гербом, логотипом и фирменными цветами РТУ МИРЭА.
- Без реальных людей, без узнаваемых зданий кампуса.
- Знак не перекрашиваем и не меняем пропорции. Два цвета знака: розовый — светлая тема и иконки приложения, синий — тёмная тема (решение Алёны 11.11). Минимальный размер — 16 px.
- Цвета иллюстраций — из `docs/design-system.md` (палитра «Табло»).
