# Промпты ChatGPT: иллюстрации пустых состояний

Для требования T2. Макеты с местами под картинки — экран «Пустые состояния» на холсте (ряды «Табло: староста, настройки, пустые состояния» и «Песочное табло»). Подготовил Claude Code 11.11.

## Как работать

Каждая картинка нужна в двух вариантах: для светлой темы (розовый Деканыч, как знак в светлой теме) и для тёмной (синий Деканыч, как знак в тёмной). Композиция и поза одинаковые, меняются только цвета.

1. Новый чат в ChatGPT. Первым сообщением — **общий стиль** (ниже) целиком.
2. Дальше по одной сцене. ChatGPT делает 3 варианта светлой версии.
3. Выбираешь один и пишешь: «Сделай тёмную версию варианта N». ChatGPT перекрашивает ту же картинку по правилам тёмной темы.
4. Начни с `empty-today` — по нему закрепляется персонаж. Остальные сцены — «в том же стиле и с тем же персонажем».
5. Файлы: `<имя>-light.png` и `<имя>-dark.png` (например, `empty-today-light.png`). Кладём в `docs/brand/` через PR, отмечаем в таблице «Что ещё нужно» в [`README.md`](README.md).
6. Запись журнала ИИ — с `<кто>` = `chatgpt`, промпт и выбранный вариант.

## Общий стиль (первое сообщение)

```
Ты рисуешь серию иллюстраций пустых состояний для мобильного кабинета студента «Деканыч» вымышленного вуза ВТУ ВИРЭА. Запомни стиль и персонажа — дальше я буду присылать сцены по одной.

Каждую сцену нужно сделать в двух вариантах — для светлой и для тёмной темы приложения. Композиция, поза и предметы в обоих вариантах одинаковые, меняются только цвета. Сначала делай 3 варианта светлой версии; тёмную делай, когда я выберу один вариант и попрошу.

Персонаж — Деканыч, маленький добрый дракончик-талисман. Его тело — скруглённая квадратная табличка (как иконка приложения) с тонким контуром. На «лице» — только пара миндалевидных драконьих глаз с узкими вертикальными зрачками; рта нет или он едва намечен. У него короткие лапки, маленькие крылья-уголки и короткий хвост. Эмоции передаются наклоном таблички, формой глаз (прищур, полузакрытые, широко открытые) и позой.

СВЕТЛАЯ ВЕРСИЯ — картинка будет лежать на молочном фоне #F7F5F0 или песочном #E8DAB8:
- Деканыч розовый: тело #F9C1CE, контур #C06A85, глаза тёмно-синие #064F6E, зрачки светло-розовые #F9C1CE.
- Предметы и линии: графит #1D1B18, слоновая кость #F3EAD3, песочный #E8DAB8, тёмно-синий #064F6E.
- Акценты: бледно-жёлтый #FBE6A0, мятно-зелёный #96D1AA, бледно-голубой #A7D4E4.

ТЁМНАЯ ВЕРСИЯ — картинка будет лежать на почти чёрном графитовом фоне #141311 или тёмно-синем табло #062F42:
- Деканыч синий: тело #064F6E, контур светло-голубой #7DB1D5, глаза розовые #F9C1CE, зрачки тёмно-синие #064F6E.
- Предметы и линии светлые, чтобы читались на тёмном: контуры #F3F0EA или #A9C6D6, заливки #1F3C4E и #0A3B52, перекидные плитки — тёмно-синие #135675 со светлыми цифрами #F3F0EA.
- Акценты те же, что в светлой версии: #FBE6A0, #96D1AA, #F9C1CE.
- Никаких тёмных графитовых линий #1D1B18 — на тёмном фоне их не видно.

Общий стиль для обеих версий: плоская векторная иллюстрация, без градиентов, теней и фактур, толщина линий одинаковая, скругления мягкие. Отсылка к старым вокзальным табло: перекидные плитки с цифрами, табличка, стрелки — можно как предметы в сцене.

Формат: PNG 1024×1024, прозрачный фон, персонаж и предметы занимают центральные 70 % кадра, крупные простые формы — картинка будет показана размером 96–120 px.

Ограничения: никакого текста и букв на картинке, кроме цифр на плитках, если о них попрошу; без реальных людей и узнаваемых зданий; без герба, логотипа и фирменных цветов РТУ МИРЭА; без сходства с персонажами известных мультфильмов и игр.
```

Если ChatGPT не может сделать прозрачный фон — попроси светлую версию на фоне #F7F5F0, тёмную на фоне #141311: так картинки тоже встанут в макеты.

## Сцены

### `empty-today.png` — «Пар нет — выходной»

```
Сцена: выходной, пар нет. Деканыч лежит в шезлонге или на мягкой подушке рядом с маленьким вокзальным табло, на табло две пары перекидных плиток с прочерками «– –» вместо времени. Глаза довольно прищурены. Рядом чашка с паром. Настроение — спокойный отдых.
```

### `empty-requests.png` — «Заявок пока нет»

```
Сцена: заявок пока нет. Деканыч держит в лапках пустую папку-конверт и с любопытством заглядывает в неё, глаза широко открыты. Рядом — маленький маршрут из четырёх точек на линии, как отслеживание посылки, все точки пустые. Настроение — «можно начать».
```

### `empty-notifications.png` — «Новых уведомлений нет»

```
Сцена: новых уведомлений нет. Деканыч дремлет, свернувшись калачиком рядом с маленьким колокольчиком, который молчит. Глаза закрыты — две тонкие дуги цвета глаз. Над ним маленькая луна или три «z» в виде простых фигур (не букв). Настроение — тишина, всё спокойно.
```

### `empty-deadlines.png` — «Дедлайнов на неделе нет»

```
Сцена: дедлайнов на неделе нет. Деканыч стоит рядом с небольшим флажком мятно-зелёного цвета #96D1AA, как будто дошёл до финиша, одна лапка поднята. Рядом календарный листок без отметок. Настроение — лёгкость, «можно выдохнуть».
```

### `error-sync.png` — «Расписание не обновилось»

```
Сцена: расписание не обновилось, связь потерялась. Деканыч держит в лапках два конца отсоединённого провода и пытается их соединить, глаза сосредоточенные. Рядом маленькое табло, плитки на нём застыли наполовину перевёрнутыми. Настроение — не тревожное, «сейчас починим». Без красного цвета.
```

## Если что-то не так

- Персонаж получился котом или совой → «Это дракончик: добавь маленькие крылья-уголки и короткий хвост с шипом, уши убери».
- Появился текст или буквы → «Убери весь текст, оставь только формы».
- Цвета уехали → «Используй только цвета из палитры, без градиентов и теней».
- В тёмной версии изменилась поза или предметы → «Возьми выбранную светлую картинку и только перекрась её по правилам тёмной версии, композицию не меняй».
- В тёмной версии не видно линий → «Сделай все контуры светлыми #F3F0EA, на тёмном фоне их не видно».
- Слишком мелкие детали → «Упрости: картинка будет размером 100 px, оставь 3–4 крупных предмета».

## Аватары-заглушки (4 тестовых аккаунта)

Аватары не изображают людей: это табличка цвета плашки с одним предметом-символом роли. Одна версия подходит для обеих тем — плашки пастельные, предметы графитовые. Отправлять в том же чате после общего стиля или в новом чате целиком.

```
Нарисуй 4 аватара-заглушки для тестовых аккаунтов кабинета «Деканыч». Это не портреты: никаких лиц, людей и фигур. Каждый аватар — скруглённый квадрат на весь кадр, заливка своим пастельным цветом, в центре — один простой предмет-символ графитового цвета #1D1B18 с заливками #F3EAD3.

1. avatar-danila — фон бледно-голубой #A7D4E4, предмет: раскрытая книга с закладкой (первокурсник).
2. avatar-ksenia — фон мятно-зелёный #96D1AA, предмет: карандаш и маленькая галочка (второй курс, учёба и допуск).
3. avatar-marat — фон серо-лавандовый #B5B1D8, предмет: флажок на древке (староста группы).
4. avatar-irina — фон бледно-жёлтый #FBE6A0, предмет: папка с бумагами и круглая печать (сотрудник дирекции).

Стиль: плоская векторная иллюстрация, без градиентов, теней и текста, толщина линий одинаковая, крупные формы — аватар будет показан размером 40 px. Формат: 4 отдельных PNG 512×512. Без сходства с гербом и символикой РТУ МИРЭА.
```

Файлы: `avatar-danila.png`, `avatar-ksenia.png`, `avatar-marat.png`, `avatar-irina.png`.
