# Модель данных

Владелец — напарник (Codex напарника). Срок — 12 ноября. Основа — разделы и роли из `docs/PRD.md`.

Что должно быть описано: сущности и связи (пользователь, роль, студент, группа, институт, дисциплина, пара и её изменения, дедлайн, уведомление и доставка по каналам, заявка и история статусов, оценка, привязка MAX, push-подписка, документ для ИИ-помощника), какие поля видит каждая роль, индексы под «Сегодня».

Правила: id — UUID; все запросы студента фильтруются по `userId` из сессии; персональные данные только вымышленные.
