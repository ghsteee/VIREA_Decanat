# Подключение GigaChat к «Деканычу»

В [личном кабинете GigaChat API](https://developers.sber.ru/docs/ru/gigachat/individuals-quickstart) создай проект и возьми готовый ключ авторизации. Для проекта физлица используется `GIGACHAT_API_PERS`. Затем положи пакет сертификатов на VPS по [инструкции](../../deploy/certs/README.md).

На VPS открой `sudoedit /opt/dekanych/.env`. Укажи настройки один раз. Готовый ключ вставь в файл сразу после знака `=`.

```dotenv
GIGACHAT_AUTH_KEY=
GIGACHAT_SCOPE=GIGACHAT_API_PERS
GIGACHAT_MODEL=GigaChat-2-Pro
GIGACHAT_CA_BUNDLE=/certs/russian_trusted_ca.pem
```

Чтобы проверить подключение **до включения помощника**, запусти следующий блок в SSH-терминале после слияния PR №81. Он берёт проверку из `main` и запускает её в одноразовом контейнере с настройками VPS.

```bash
sudo -H bash <<'CHECK'
set -euo pipefail
cd /opt/dekanych
git fetch origin main
git show FETCH_HEAD:scripts/gigachat/check.mjs |
  docker compose run -T --rm --no-deps --entrypoint node app --input-type=module
CHECK
```

Строки `OAuth: OK`, `Доступ к выбранной модели: OK` и `Ответ с пунктом 3.1: OK` подтверждают авторизацию, доступность модели и ответ на один учебный вопрос. Скрипт выводит статусы проверок и доступные модели при ошибке выбора. Ключ, токен и содержимое ответа остаются в контейнере.

- `сертификаты: ENOENT` — файл отсутствует по пути, который видит контейнер.
- `OAuth: HTTP_401` — проверь ключ авторизации, проект и тип доступа.
- `MODEL_NOT_AVAILABLE` — выбери точное имя из списка моделей, который показала проверка.
- `ответ модели: HTTP_429` — проверь лимиты проекта GigaChat.
- `INVALID_COMPLETION` или `UNEXPECTED_SECTION` — модель вернула ответ в неожиданном формате или выбрала другой пункт.
- `ENOTFOUND`, `ECONNREFUSED` или `ABORT_ERR` — проверь сеть VPS и подключение к OAuth на порту 9443.
- Ошибка проверки цепочки сертификатов — обнови пакет Минцифры и проверь путь. Клиент учитывает встроенные сертификаты Node.js и пакет Минцифры.

После успешной проверки установи `AI_ASSISTANT_ENABLED=on` в `.env` и обнови приложение. Войди в демо-кабинет студента и открой «Профиль» → «ИИ-помощник».
