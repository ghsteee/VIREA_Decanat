# Обновление Деканыча с Mac

Убедись, что PR с редактором сессии, портфолио и новой формой заявки уже в `main` и проверки GitHub прошли. Скопируй полный SHA верхнего коммита `main`. В Terminal на Mac войди под своим пользователем VPS. Если обычно подключаешься по IP или через SSH-алиас, используй привычное подключение.

```bash
ssh ТВОЙ_ЛОГИН_НА_VPS@dekanych.ru
```

После входа на сервер вставь этот блок целиком. По запросу введи полный SHA из GitHub. `sudo` использует права и ключ GitHub, которые настроены на VPS.

```bash
read -rp 'Полный SHA проверенного коммита main: ' release_sha
sudo bash -s -- "$release_sha" <<'DEPLOY'
set -euo pipefail
release_sha="$1"
[[ "$release_sha" =~ ^[0-9a-f]{40}$ ]]
cd /opt/dekanych
git fetch origin main
[[ "$(git rev-parse FETCH_HEAD)" == "$release_sha" ]] || {
  echo 'На GitHub уже другая вершина main. Сначала проверь новый коммит.' >&2
  exit 1
}
release_script="$(mktemp)"
trap 'rm -f -- "$release_script"' EXIT
git show "$release_sha:deploy/update-demo-with-migrations.sh" > "$release_script"
bash "$release_script" "$release_sha"
DEPLOY
```

Скрипт собирает новый образ при работающем сайте. Затем останавливает приложение на время резервного копирования PostgreSQL и существующих вложений, применяет миграции и запускает новую версию. Копии появятся в `/var/backups/dekanych/`. Если проверка запуска не пройдёт, скрипт вернёт предыдущий образ, а добавленные таблицы и поля останутся в базе. При повторном запуске используй текущий проверенный SHA `main`.

Утренний cron из [общей инструкции](deploy.md) запускает полный сброс демонстрационной базы. Если он настроен на VPS, убери эту строку из `sudo crontab -e` перед началом работы с портфолио. Скрипт обновления сохраняет существующие записи и не запускает `db:seed`.

После сообщения «Обновлено» введи `exit`, чтобы вернуться в Terminal на Mac, и проверь доступность сайта. Затем войди как студент и проверь создание заявки и выгрузку PDF/ZIP. Для проверки редактора сессии войди как сотрудник дирекции.

```bash
curl -fsS -o /dev/null -w 'HTTP %{http_code}\n' https://dekanych.ru/login
```

По завершении первого обновления формы контроля для существующих дисциплин можно назначить в «Сессии» от имени дирекции. Студент увидит назначенные экзамены и зачёты внутри предметов. Список портфолио в существующей серверной базе наполняется через интерфейс.
