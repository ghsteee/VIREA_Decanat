# Словарь

| Термин | Что значит |
| --- | --- |
| ВТУ ВИРЭА | Вымышленный вуз в интерфейсе прототипа. «В» — вымышленный |
| РТУ МИРЭА | Реальный вуз команды, прообраз. В интерфейсе не упоминается, кроме плашки «прообраз — РТУ МИРЭА» |
| Институт | Подразделение вуза (в МИРЭА вместо факультета). Примеры в демо-данных: ИКБ, ИИИ, ИТХТ |
| Дирекция института | Аналог деканата: справки, заявления, объявления. Сотрудник дирекции — роль `staff` |
| Группа | Учебная группа, формат кода как в МИРЭА: `БИСО-03-25` (направление-номер-год поступления). Номера в демо вымышленные |
| Староста | Студент группы с правом публиковать изменения, дедлайны и объявления для своей группы |
| Пара | Занятие 90 минут: лекция, практика или лабораторная |
| Учебная неделя | Номер недели семестра; в МИРЭА расписание зависит от чётности недели |
| Изменение | Перенос, отмена, смена аудитории или формата пары. Показывается как «было → стало» |
| Дедлайн | Срок: сдача работы, пересдача, приём заявлений. Публикует дирекция, преподаватель или староста |
| Допуск к сессии | Право сдавать экзамен по дисциплине, если выполнены требования (лабы, контрольные) |
| Справка | Документ по заявке: об обучении, для военкомата, о стипендии |
| Заявление | Заявка на пересдачу, повышенную стипендию, матпомощь |
| Слот выдачи | Время, когда можно забрать бумажную справку; предлагаем только окна без пар студента |
| СДО | Система дистанционного обучения (задания и материалы курсов). Вне рамок прототипа |
| E-mail-уведомление | Письмо на подтверждённый адрес со ссылкой в личный кабинет |
| Web push | Уведомления браузера через PWA (стандарт VAPID). На iPhone — только после «На экран Домой» |
| Must / Should / Could | Приоритеты требований в PRD: обязательно к 16.11 / фишки 17–19.11 / если останется время |
| S1–S9 | Ключевые сценарии из PRD, по ним e2e-тесты и демо жюри |
| R3, N2, … | Номера требований из PRD, пишутся в коммитах и PR |
