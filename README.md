# Деканыч — цифровой деканат ВТУ ВИРЭА

![Деканыч](docs/brand/dekanych-logo.svg)

Прототип личного кабинета студента для хакатона «Цифровой деканат будущего».

> **Концепт для хакатона.** ВТУ ВИРЭА — вымышленный вуз, прообраз — РТУ МИРЭА. Это не официальный сервис, все данные вымышленные.

## Идея

По опросу 20 студентов главная боль — изменения в расписании: 75% оценили то, как узнают о переносах, на 1–2 из 5, а 85% узнают о них от старосты. Поэтому кабинет сообщает о переносах пар и дедлайнах через web push и письма на подтверждённую почту. Цель демонстрации переноса — получение обоих уведомлений за 60 секунд.

Разделы: Сегодня · Расписание · Учёба (успеваемость и дедлайны) · Заявки и справки · Профиль. Фишки: ИИ-помощник по документам, роль старосты, поиск, PDF-справка с QR.

## Запуск

Нужен Node.js 22 или новее.

```bash
npm install
```

```bash
npm run dev
```

Приложение откроется на http://localhost:3000. Проверки перед PR:

```bash
npm run lint && npm run typecheck && npm run build
```

Для базы нужен PostgreSQL 16 и `DATABASE_URL` в `.env`. Применить миграции и открыть данные:

```bash
npm run db:migrate
```

```bash
npm run db:studio
```

Демо-данные (4 тестовых аккаунта, расписание семестра, изменения «на сегодня», оценки, заявки, демо-положение для помощника) — полностью пересоздают базу:

```bash
npm run db:seed
```

Логины: `d.severov` (студент), `k.lavrova` (студентка, риск недопуска), `m.gainullin` (староста), `i.sokolova` (дирекция). Пароль берётся из `SEED_PASSWORD` или генерируется и печатается в консоль; в репозиторий не сохраняется.

Секреты — только в `.env` (образец — `.env.example`). Деплой на VPS — [`docs/setup/deploy.md`](docs/setup/deploy.md).
