# Деканыч — цифровой деканат ВТУ ВИРЭА

![Деканыч](docs/brand/dekanych-logo.svg)

Прототип личного кабинета студента для хакатона «Цифровой деканат будущего».

> **Концепт для хакатона.** ВТУ ВИРЭА — вымышленный вуз, прообраз — РТУ МИРЭА. Это не официальный сервис, все данные вымышленные.

## Идея

По опросу 20 студентов главная боль — изменения в расписании: 75% оценили то, как узнают о переносах, на 1–2 из 5, а 85% узнают о них от старосты. Поэтому кабинет сообщает о переносах пар и дедлайнах через web push и письма на подтверждённую почту. Цель демонстрации переноса — получение обоих уведомлений за 60 секунд.

Разделы: Сегодня · Расписание · Учёба (успеваемость и дедлайны) · Заявки и справки · Профиль. Фишки: ИИ-помощник по документам, роль старосты, поиск, PDF-справка с QR.

## Запуск

Нужны Node.js 22 или новее и PostgreSQL 16. Для локальной базы можно использовать Docker Desktop.

```bash
npm ci
npm run setup:local
docker compose -f compose.local.yml up -d --wait
npm run db:deploy
npm run db:seed
```

```bash
npm run dev
```

Приложение откроется на http://localhost:3000. Вход без пароля — четыре кнопки демо-аккаунтов. `setup:local` создаёт `.env` со случайными секретами и подключением к базе на `127.0.0.1:5434`, существующий файл сохраняет. Если `.env` уже есть, сверь `POSTGRES_PASSWORD`, `DATABASE_URL`, `SESSION_SECRET` и `DEMO_LOGIN` с локальной конфигурацией. При изменении пароля существующего Docker-тома пароль пользователя БД сам не меняется.

Без Docker создай свою базу PostgreSQL 16, скопируй `.env.example` в `.env`, заполни `DATABASE_URL`, `SESSION_SECRET` (не менее 32 случайных символов), `SEED_PASSWORD` и `DEMO_LOGIN=on`. Затем выполни миграции, сиды и `npm run dev`. SMTP и VAPID нужны только для внешних уведомлений, остальные разделы работают без них.

Остановить локальную базу с сохранением данных — `docker compose -f compose.local.yml stop`. Следующий запуск — та же команда `up -d --wait`, затем `npm run dev`; сид заново не требуется. Состояние приложения и связи с БД — `/api/health` (HTTP 200 или 503 без подробностей подключения).

Проверки перед PR:

```bash
npm run lint && npm run typecheck && npm run test:unit && npm run build
```

Открыть данные локальной базы:

```bash
npm run db:studio
```

```bash
npm run test:e2e
```

E2E изменяют данные: используй отдельную тестовую базу. В CI также запускается `npm run test:integration` с `INTEGRATION_TEST_DATABASE=on` до старта приложения. Тест проверяет отмену устаревших доставок и обработку нескольких пакетов без внешних сетевых запросов.

Демо-данные (4 основных тестовых аккаунта, расписание семестра, изменения «на сегодня», оценки, заявки, демо-положение для помощника) — полностью пересоздают базу. Сохранённые заявки и подписки удаляются:

```bash
npm run db:seed
```

Логины: `d.severov` (студент), `k.lavrova` (студентка, риск недопуска), `m.gainullin` (староста), `i.sokolova` (дирекция). Пароль берётся из `SEED_PASSWORD` или генерируется и печатается в консоль; в репозиторий не сохраняется.

Секреты — только в `.env` (образец — `.env.example`). Деплой на VPS — [`docs/setup/deploy.md`](docs/setup/deploy.md).
