# Цифровой деканат ВТУ ВИРЭА

Прототип личного кабинета студента для хакатона «Цифровой деканат будущего».

> **Концепт для хакатона.** ВТУ ВИРЭА — вымышленный вуз, прообраз — РТУ МИРЭА. Это не официальный сервис, все данные вымышленные.

## Идея

По опросу 20 студентов главная боль — изменения в расписании: 75% оценили то, как узнают о переносах, на 1–2 из 5, а 85% узнают о них от старосты. Поэтому кабинет сообщает о переносах пар и дедлайнах через web push и письма на подтверждённую почту. Цель демонстрации переноса — получение обоих уведомлений за 60 секунд.

Разделы: Сегодня · Расписание · Учёба (успеваемость и дедлайны) · Заявки и справки · Профиль. Фишки: ИИ-помощник по документам, роль старосты, поиск, PDF-справка с QR.
